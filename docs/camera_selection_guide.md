# 物理相机选型指南——基于 modeld 模型输入要求

## 模型输入规格

modeld 有两个图像输入，各对应一个「虚拟相机」：

| 输入 | 名称 | 分辨率 | 焦距 | 水平 FOV | cx | cy | 用途 |
|------|------|--------|------|---------|----|----|------|
| `img` | MEDMODEL | 512×256 | **910** | 31.4° | 256.0 | 47.6 | 主感知（车道线、前车） |
| `big_img` | SBIGMODEL | 512×256 | **455** | 58.8° | 256.0 | 151.8 | 辅助广角感知 |

`get_warp_matrix()` 从物理相机原图裁剪/缩放到这些虚拟相机画面。**物理相机的焦距与模型焦距的比值决定了感知质量。**

## 核心约束

### 约束 1：焦距下限（MEDMODEL 不上采样）

```
f_camera ≥ f_medmodel = 910
```

当 `f_camera / 910 < 1` 时，模型输入像素由少于一个物理像素支撑（上采样），图像模糊，感知退化。

**由此推导最低水平分辨率**：

```
f_camera = (W / 2) / tan(HFOV / 2) ≥ 910
→ W ≥ 2 × 910 × tan(HFOV / 2)
```

| 水平 FOV | tan(HFOV/2) | 最低宽度 (MEDMODEL) | 常见分辨率 |
|---------|-------------|-------------------|----------|
| 40° | 0.364 | 663 | 720p 可用 |
| 50° | 0.466 | 848 | 960×540 可用 |
| 60° | 0.577 | **1051** | 1080p 可用 |
| 70° | 0.700 | 1274 | 1280×720 刚好 |
| 80° | 0.839 | 1527 | 1920×1080 可用 |
| 90° | 1.000 | 1820 | 1920×1080 可用 |
| 100° | 1.192 | 2169 | 需要 2.5K+ |
| 120° | 1.732 | 3154 | 需要 4K |

### 约束 2：FOV 覆盖（SBIGMODEL 不裁剪）

如果同一个相机同时为 `img` 和 `big_img` 供图（单相机双目模式）：

```
相机 HFOV ≥ SBIGMODEL HFOV = 58.8°
```

FOV 不足时，SBIGMODEL 边缘采样到图像边界外，被 clamp 为边缘像素，导致感知异常。

### 约束 3：两个约束的交叉

**单相机同时满足 MEDMODEL 和 SBIGMODEL** 时，两个约束同时生效：

```
f_camera ≥ 910        （MEDMODEL 不上采样）
HFOV ≥ 58.8°          （SBIGMODEL 完整覆盖）
→ W ≥ 2 × 910 × tan(29.4°) = 1026
```

**单相机双目模式的最低要求：宽度 ≥ 1026 像素，HFOV ≥ 59°。**

## 质量分级

`f_camera / f_model` 比值越高，MEDMODEL 获得的信息越丰富：

| 比值范围 | 质量 | 含义 |
|---------|------|------|
| < 1.0 | ❌ 不可用 | 上采样，像素信息不足 |
| 1.0 ~ 1.3 | ⚠️ 可用 | 勉强降采样，细节有限 |
| 1.3 ~ 2.0 | ✅ 良好 | 充足降采样 |
| 2.0 ~ 3.0 | ✅✅ 优秀 | 类似 openpilot fcam (2.91x) |
| > 3.0 | ✅✅ 优秀 | 信息富余，收益递减 |

### 读表示例

- **1280×720 + HFOV 60°**：比值 1.22，可用（上一次讨论的结论）
- **1920×1080 + HFOV 60°**：比值 1.83，良好
- **1920×1080 + HFOV 90°**：比值 1.05，勉强可用
- **3840×2160 + HFOV 120°**：比值 1.22，可用（即方案A 的 scale=2）

## 单相机双目模式选型建议

同一个相机同时为 MEDMODEL 和 SBIGMODEL 供图时，需要同时满足：
- MEDMODEL：f_camera ≥ 910（比值 ≥ 1.0，推荐 ≥ 1.3）
- SBIGMODEL：HFOV ≥ 58.8°（推荐 ≥ 62° 留余量）

**推荐配置**（按优先级排序）：

| 优先级 | 分辨率 | HFOV | MEDMODEL 比值 | SBIGMODEL 覆盖 | 说明 |
|--------|--------|------|-------------|---------------|------|
| ★★★ | 1920×1080 | 60° ~ 70° | 1.83 ~ 1.51 | ✅ (60° 刚好，70° 充裕) | **性价比最优** |
| ★★★ | 2560×1440 | 60° ~ 80° | 2.44 ~ 1.68 | ✅ | 高质量 |
| ★★ | 1280×720 | 60° | 1.22 | ✅ (刚好) | 最低可用配置 |
| ★ | 3840×2160 | 80° ~ 120° | 2.52 ~ 1.22 | ✅ | 超广角需要 4K |

## 其他选型注意事项

### 镜头畸变

模型假设**理想针孔相机**（无畸变）。物理相机尤其广角镜头通常有桶形畸变，需要在送入 VisionIPC 之前做畸变校正（undistortion），否则 warp 变换的几何映射会出错。FOV 越大，畸变越严重，校正开销越大。

### cy 偏移与安装角度

MEDMODEL 的 cy=47.6（图像上方 19%），意味着模型期望大部分画面是路面。物理相机安装时应朝向前方偏下，或通过标定系统的 pitch 补偿。若相机安装角度偏差过大，warp 可能采样到图像边界外。

### 帧率

modeld 以 20 FPS 运行（`MODEL_RUN_FREQ`）。物理相机帧率应 ≥ 20 FPS，推荐 30 FPS 以上以留余量。

### 全局快门 vs 卷帘快门

行车场景中卷帘快门（rolling shutter）会在快速运动时产生果冻效应。openpilot 原装相机使用全局快门（global shutter）传感器（AR0231/OX03C10）。对于低速场景（< 60 km/h），卷帘快门基本可接受。

### 动态范围

行车场景光照变化大（隧道出入口、逆光）。推荐 HDR 或高动态范围传感器，避免过曝/欠曝导致感知丢失。
