### 1. 人工审查清洗数据（优先）

用可视化工具逐帧审查，按 `d` 禁用标注质量差的帧：

```bash
python tools/dashcam/viz/inspect_clean_log.py \
    --dataset-dir /nfs/openpilot-datasets/multi_height-0312/ \
    --clean-log data/multi_height-0312/clean_log.txt
```

重点关注：
- 车道线标注明显偏离实际车道的帧
- 十字路口/匝道等车道线不明确的帧
- 前车检测明显错误的帧（漏检或误检）
- 图像质量异常的帧
